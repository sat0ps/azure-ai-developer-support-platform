# Azure AI Developer Support Platform

Azure-native demonstration of a secure, evaluated developer-support workflow, designed around Microsoft Foundry and Azure DevOps.

## Roadmap

- **Stage 0:** Infrastructure as Code, Azure Pipelines, agent versioning, evaluations and release controls.
- **Stage 1:** Developer knowledge retrieval using Azure AI Search and a Foundry agent.
- **Stage 2:** Deployment Concierge observing a sample application deployment.
- **Stage 3:** Read-only failure investigation with evidence-backed recommendations.

This repository uses synthetic sample data only. No production credentials, internal employer documents or proprietary configuration should be committed.

> Status: foundation in progress. No Azure resources or agents are deployed yet.
